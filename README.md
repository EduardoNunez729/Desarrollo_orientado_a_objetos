  - Descripción general del sistema:
    Este proyecto corresponde a la Evaluación Semana 3 de la asignatura Desarrollo Orientado a Objetos I.
    Se trata de un sistema orientado a objetos desarrollado en Java, cuyo objetivo es modelar y gestionar entidades representativas de un dominio real, aplicando los principios de encapsulamiento, composición, herencia, polimorfismo e interfaces.

El proyecto fue desarrollado a partir de un caso contextualizado, la empresa Llanquihue Tour carece de un sistema estructurado para representar la información de las personas involucradas en sus procesos, lo que provoca: Información duplicada y desorganizada, Gestión manual de registro, falta de diferenciación de roles ademas de poca reutilización de estructuras.
Se diseñara un modelo de clases que represente adecuadamente a las personas vinculadas a la organización, considerando atributos, relaciones y principios de encapsulamiento, para establecer una base sólida sobre la cual construir el sistema completo en fases futuras.

├── model/       # Clases de dominio (Cliente, Empleado, EncargoSM3 (persona)).
